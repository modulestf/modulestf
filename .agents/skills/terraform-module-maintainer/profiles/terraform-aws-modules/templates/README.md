# Terraform Module Templates

Template files for creating Terraform modules for any provider following terraform-aws-modules standards.

## Usage

These templates are used by the `terraform-module-maintainer` skill. The skill instructs the agent to:

1. **Copy static files verbatim** - `.editorconfig`, `.gitignore`, `.releaserc.json`, GitHub workflows
2. **Copy then update** - `.pre-commit-config.yaml` (then `pre-commit autoupdate`)
3. **Use as structural reference** - `main.tf`, `variables.tf`, `outputs.tf`, examples, tests (populated from provider schema, not copied verbatim)

The `wrappers/` directory is auto-generated by the `terraform_wrapper_module_for_each` pre-commit hook - no templates needed.

See [templates-map.md](../templates-map.md) for the full mapping.

## Template Categories

### Static Files (Copy Verbatim)

| File | Purpose |
|------|---------|
| `.editorconfig.template` | Code style (2-space indent, UTF-8, LF) |
| `.gitignore.template` | Git exclusions (.terraform, .tfstate, .tfvars) |
| `.releaserc.json.template` | Semantic release configuration |
| `github-workflows-pre-commit.yml.template` | CI/CD: pre-commit validation |
| `github-workflows-release.yml.template` | CI/CD: semantic release |
| `github-workflows-lock.yml.template` | CI/CD: lock threads (`.github/workflows/lock.yml`) |
| `github-workflows-pr-title.yml.template` | CI/CD: validate PR title (`.github/workflows/pr-title.yml`) |
| `github-workflows-stale-actions.yaml.template` | CI/CD: mark or close stale issues and PRs (`.github/workflows/stale-actions.yaml`) |

### Pre-Commit Config (Copy Then Update)

| File | Purpose |
|------|---------|
| `.pre-commit-config.yaml.template` | Pre-commit hooks (run `pre-commit autoupdate` after copying) |

### Provider-Configured Files

| File | Purpose |
|------|---------|
| `versions.tf.template` | Terraform and provider version constraints, with the `provider_meta` user agent: [Module layout](../PROFILE.md#module-layout) |
| `example-versions.tf.template` | An example's version constraints, with no `provider_meta` |

### Skeletal Templates (Structural Reference)

| File | Purpose |
|------|---------|
| `main.tf.template` | Core structure: locals with create, multi-provider data source examples |
| `variables.tf.template` | Core variables: create, putin_khuylo, name, tags. `putin_khuylo` at the root only: [Module layout](../PROFILE.md#module-layout) |
| `outputs.tf.template` | Output pattern guidance (use `null` fallbacks, not `""`) |
| `iam.tf.template` | AWS IAM role/policy structure (with notes for GCP/Azure alternatives) |

### Example Templates

| File | Purpose |
|------|---------|
| `example-complete-main.tf.template` | Complete example with module + disabled call |
| `example-complete-outputs.tf.template` | Example output guidance |
| `example-README.md.template` | Example documentation |

### Other

| File | Purpose |
|------|---------|
| `README.md.template` | Module root README with terraform-docs markers |
| `test-basic.tftest.hcl.template` | Basic test structure |

## Placeholders

| Placeholder | Example |
|-------------|---------|
| `{{provider}}` | `aws`, `google`, `azurerm` |
| `{{provider_source}}` | `hashicorp/aws`, `hashicorp/google` |
| `{{provider_version}}` | `6.0`, `6.14`, `4.0` |
| `{{SERVICE_NAME}}` | `WAF v2 Web ACL`, `Compute Instance` |
| `{{service}}` | `wafv2`, `compute` |
| `{{resource_type}}` | `wafv2_web_acl`, `compute_instance` |
| `{{MODULE_NAME}}` | `WAF v2`, `Compute Instance` |
| `{{module_name}}` | `wafv2`, `compute-instance` |
| `{{service_name}}` | `wafv2`, `compute` |
