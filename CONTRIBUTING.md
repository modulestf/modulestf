# Contributing

The modulestf maintainers develop this repository. It does not accept pull requests; pull requests from outside the maintainer team are closed without review. Bug reports, questions and feature requests are welcome as [issues](https://github.com/modulestf/modulestf/issues).

## Opening a useful issue

- Search the existing issues first.
- Say what you expected and what happened instead.
- Name the skill or workflow, the agent tool and its version, and the commit of this repository you used.
- For a review, link the pull request it reviewed and quote the finding or the verdict you disagree with.
- For a feature request, describe the problem you want solved, not only the change you have in mind.
- Remove account ids, credentials and any other secrets before you post.

## Security

Do not report a security vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md).
